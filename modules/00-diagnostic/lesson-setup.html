БЛОК 0 · Налаштування Arduino IDE та драйвера CH340

Повний посібник із підготовки комп'ютера до роботи зі справжнім обладнанням із набору ТЕКО: встановлення середовища розробки, системного драйвера USB-UART та перевірка першого зв'язку.

⏱ ~30 хв 📦 Обладнання ТЕКО: плата Arduino Uno + кабель USB 💻 ОС: Windows 10 / 11

Симулятори в браузері (Wokwi та Tinkercad) чудові для швидкого старту. Але справжній інженерний кайф починається тоді, коли твоя програма оживає на реальній фізичній платі, в яку встромлені справжні дроти та світяться живі діоди.

У наборах ТЕКО використовується доступна та надійна копія плати Arduino Uno R3. Вона має одну важливу технічну особливість: за передачу даних через USB у ній відповідає мікросхема WCH CH340. Без спеціального драйвера комп'ютер просто не побачить плату. Нижче — вичерпна покрокова інструкція, як налаштувати все за 15 хвилин.

🛡 Це робиться лише один раз!
Після того, як драйвер та Arduino IDE встановлені й перевірені, твій комп'ютер у майстерні чи вдома буде миттєво впізнавати будь-які плати з набору ТЕКО без додаткових налаштувань.
1

Встановлення програми Arduino IDE

Arduino IDE — це безкоштовна офіційна програма, де пишуть код, знаходять помилки та завантажують прошивку в пам'ять мікроконтролера через USB-кабель.

  1. Перейди на офіційний сайт завантаження: arduino.cc/en/software.
  2. Для Windows обери версію Windows Win 10 and newer, 64 bits (рекомендовано Arduino IDE 2.3.x) або Windows ZIP file (портативна версія, яка не вимагає прав адміністратора на комп'ютерах у коледжі).
  3. На сторінці подяки завантаження натисни кнопку «JUST DOWNLOAD» (це безкоштовно).
  4. Запусти завантажений файл (наприклад, arduino-ide_..._Windows_64bit.exe), погодься з ліцензійною угодою та натискай Next → Install.
2

Встановлення драйвера CH340 для плати ТЕКО

Поглянь на свою плату Arduino з набору ТЕКО біля металевого роз'єму USB-B. Там розташована невелика прямокутна мікросхема з маркуванням CH340G (або CH340C). Це міст, який перекладає команди з USB на зрозумілу процесору послідовну мову UART.

Покрокова інструкція зі встановлення драйвера:

  1. Завантаж офіційний інсталятор драйвера: WCH CH341SER.EXE (офіційний сайт виробника).
  2. Запусти завантажений файл CH341SER.EXE. Якщо система запитає дозвіл — обери «Так» (запуск від імені адміністратора).
  3. У вікні інсталятора натисни одну кнопку: INSTALL.
  4. Зачекай 5–10 секунд, доки з'явиться вікно: «Driver install success!». Натисни OK і закрий інсталятор.
3

Перевірка зв'язку в Диспетчері пристроїв Windows

Тепер перевіримо, чи бачить Windows твою плату:

  1. Підключи плату Arduino Uno до комп'ютера синім кабелем USB. На платі має засвітитися зелений світлодіод ON.
  2. Натисни на клавіатурі комбінацію Win + X і в меню обери Диспетчер пристроїв (або натисни Win + R, введи devmgmt.msc і натисни Enter).
  3. Знайди розділ «Порти (COM і LPT)» і розкрий його.
✅ Ознака успішного підключення
У списку має з'явитися рядок: USB-SERIAL CH340 (COM3) (номер порту може бути іншим: COM4, COM5 тощо).
Запам'ятай цей номер COM-порту — саме його ми вкажемо в середовищі розробки!
4

Налаштування в самій Arduino IDE

Відкрий встановлену програму Arduino IDE та налаштуй два обов'язкові параметри:

  1. Обери модель плати:
    • У верхньому меню обери Tools (Інструменти) → Board (Плата) → Arduino AVR Boards → Arduino Uno.
  2. Обери COM-порт підключення:
    • У меню обери Tools (Інструменти) → Port (Порт) → обери порт із написом COMx (який ти бачив у Диспетчері пристроїв).
5

Тест за 60 секунд: Завантажуємо перший Blink

Переконайся, що зв'язок працює і плата слухається твоїх команд:

  1. У меню Arduino IDE обери: File (Файл) → Examples (Приклади) → 01.Basics → Blink.
  2. Натисни круглу кнопку зі стрілкою ➜ Upload (Завантажити) у верхньому лівому кутку.
  3. Подивися на плату ТЕКО: в момент завантаження на ній почнуть дуже швидко блимати два крихітні світлодіоди з літерами TX та RX (це йде передача байтів коду).
  4. Внизу екрана в чорному вікні з'явиться зелений напис: «Done uploading» (Завантаження завершено).
🎉 Вітаємо, робоче місце повністю готове!
На платі ТЕКО ритмічно блимає вбудований світлодіод L раз на секунду. Зв'язок налаштовано бездоганно.
!

Швидка допомога: типові проблеми та як їх вирішити

🔴 Плата світиться (зелений ON горить), але в списку Портів (COM) нічого немає

Причина: У 90% випадків винен кабель USB. Багато тонких кабелів від телефонів є «тільки для зарядки» і не мають внутрішніх ліній передачі даних (D+ та D-).

Рішення: Візьми товстий синій кабель із набору ТЕКО або спробуй вставити його в інший USB-порт на задній панелі комп'ютера.

🟡 У Диспетчері пристроїв є «USB2.0-Serial» із жовтим знаком оклику

Причина: Драйвер CH340 не встановився або Windows заблокувала його встановлення.

Рішення: Запусти CH341SER.EXE ще раз, спочатку натисни UNINSTALL (видалити старий), а потім INSTALL (встановити наново).

🟠 Помилка в Arduino IDE: «avrdude: stk500_recv(): programmer is not responding»

Причина: Обрано неправильний COM-порт, або порт зайнятий іншою програмою (наприклад, слайсером Cura, Pronterface для 3D-принтера чи стороннім монітором порту).

Рішення: Закрий інші програми для 3D-принтерів, перевір номер COM-порту в меню Tools → Port і спробуй завантажити скетч ще раз.

🔵 На комп'ютері в коледжі немає прав адміністратора для встановлення

Рішення: Завантаж з офіційного сайту Arduino IDE у форматі ZIP (Portable). Її не треба встановлювати: розпакуй архів у свою робочу папку на диску D:\ та запускай arduino-ide.exe напряму.
