01

Встановлення середовища Arduino IDE

Офіційна безкоштовна програма для написання коду C++ та прошивки плати.

Браузерні симулятори (Wokwi) незамінні для швидких експериментів без ризику. Але справжня робота мейкера починається тоді, коли створений код завантажується в пам'ять реальної фізичної плати ТЕКО.

  1. Перейди на офіційну сторінку завантаження: arduino.cc/en/software ↗.
  2. Для комп'ютера на Windows обери версію Windows Win 10 and newer, 64 bits (інсталятор) або Windows ZIP file (портативна версія, яку можна запускати без прав адміністратора з флешки).
  3. На сторінці пропозиції донату натисни сіру кнопку «JUST DOWNLOAD».
  4. Запусти завантажений файл і заверши встановлення стандартними кліками Next → Install.
02

Чому платі ТЕКО потрібен драйвер CH340?

Технічний секрет мікросхеми перекладача між USB та процесором.

Поглянь на свою плату Arduino з набору ТЕКО біля металевого гнізда USB. Там припаяна прямокутна чорна мікросхема з маркуванням CH340G (або CH340C). Її завдання — перетворювати пакети даних сучасного USB-інтерфейсу в послідовний протокол UART, яким спілкується головний процесор ATmega328P.

Оригінальні плати Arduino з Італії використовують інший дорогий чип, а доступні набори ТЕКО — перевірений і надійний CH340. Для роботи з ним операційній системі Windows потрібен один системний драйвер.

🛡 Встановлення виконується лише один раз:
  1. Завантаж офіційний інсталятор виробника WCH: CH341SER.EXE ↗.
  2. Запусти файл від імені адміністратора.
  3. У вікні, що з'явиться, натисни лише одну кнопку — INSTALL.
  4. За 5–10 секунд з'явиться повідомлення «Driver install success!». Готово!
03

Перевірка в Диспетчері пристроїв Windows

Як переконатися, що комп'ютер побачив плату, і дізнатися номер COM-порту.

  1. Підключи плату Arduino Uno до комп'ютера синім кабелем USB. На платі має засвітитися зелений світлодіод ON.
  2. Натисни комбінацію клавіш Win + X і обери Диспетчер пристроїв (або натисни Win + R, введи devmgmt.msc і натисни Enter).
  3. Знайди та розкрий гілку «Порти (COM і LPT)».
✅ Ознака успішного розпізнавання:

У списку повинен з'явитися рядок: USB-SERIAL CH340 (COM3) (номер порту може бути іншим: COM4, COM5 тощо). Номер COM-порту — це віртуальний номер дверцят, через які ми надсилатимемо прошивку.

05

Налаштування в самій програмі Arduino IDE

Дві обов'язкові дії перед натисканням кнопки Upload.

  1. Вибір моделі мікроконтролера:

    У верхньому меню обери: Tools (Інструменти) → Board (Плата) → Arduino AVR Boards → Arduino Uno.

  2. Вибір комунікаційного порту:

    У меню обери: Tools → Port (Порт) → COMx (Arduino Uno) (номер, що з'явився в Диспетчері пристроїв).

  3. Тестове завантаження:

    Відкрий класичний приклад: File → Examples → 01.Basics → Blink і натисни круглу кнопку зі стрілкою ➜ Upload (Завантажити).

    На платі заблимають жовті діоди TX/RX, а внизу з'явиться напис «Done uploading» — після чого вбудований світлодіод L почне ритмічно блимати раз на секунду!

06

Діагностика: 3 головні проблеми з CH340 та кабелем

Якщо комп'ютер не бачить плату — перевір за цим алгоритмом.

🔌 Підступний кабель «лише для зарядки»

Деякі дешеві кабелі USB мають усередині лише 2 жили для живлення, але не мають сигнальних жил D+ та D-. Світлодіод ON горітиме, але комп'ютер не подасть жодного звуку підключення. Завжди використовуй якісний товстий синій кабель із набору ТЕКО.

❌ Помилка «avrdude: ser_open()»

Свідчить про те, що обрано неправильний COM-порт, або попередній сеанс Serial Monitor заблокував порт, або кабель відійшов під час прошивки. Слід закрити сторонні програми та переобрати порт у меню Tools.

⚠️ Знак оклику в Диспетчері пристроїв

Якщо біля CH340 горить жовтий трикутник — драйвер не встановився коректно через антивірус або політику безпеки. Потрібно повторити запуск CH341SER.EXE від імені адміністратора.

07

AI-ментор: діагностика збою прошивки

Шаблон звернення до штучного інтелекту, якщо плата не відповідає.

🤖 Шаблон промпту для аналізу збою прошивки: 
Я налаштовував зв'язок плати Arduino Uno (чіп CH340) з комп'ютером на Windows 11 через Arduino IDE 2.3.
Симптом: у консолі середовища з'явилася помилка «avrdude: stk500_recv(): programmer is not responding».
Що вже перевірено:
1. Світлодіод ON на платі світиться зеленим.
2. У Диспетчері пристроїв плата відображається як USB-SERIAL CH340 на порту COM4.
3. У меню Tools обрано плату Arduino Uno та порт COM4.
Запитання: які 3 найімовірніші причини блокування передачі скетчу (наприклад, зайняті піни 0/1 (RX/TX), зависання завантажувача Bootloader) та як безпечно перезавантажити плату кнопкою Reset під час прошивки?
