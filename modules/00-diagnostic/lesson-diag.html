1

Компетентність 1: Електричні кола та струм

Мікроконтролер Arduino живиться від напруги 5V, а світлодіоди з набору ТЕКО зазвичай витримують струм не більше 20 мА (0.02 А).

Питання 1.1: Що станеться, якщо підключити звичайний червоний світлодіод до 5V без резистора?

2

Компетентність 2: Алгоритми та C++ логіка

У мікроконтролерах код виконується циклічно. Подивись на фрагмент коду для кнопки з підтяжкою INPUT_PULLUP:

int state = digitalRead(2);
if (state == LOW) {
  digitalWrite(13, HIGH);
} else {
  digitalWrite(13, LOW);
}

Питання 2.1: Коли загориться світлодіод на піні 13?

3

Компетентність 3: Точні вимірювання та CAD-допуски

Для моделювання корпуса у Tinkercad або Fusion 360 потрібно обміряти плату Arduino штангенциркулем.

Питання 3.1: Якщо діаметр гвинта кріплення M3 становить рівно 3.0 мм, який діаметр отвору слід закласти в 3D-моделі для вільного проходження гвинта з урахуванням розширення пластику PLA?

4

Компетентність 4: 3D-друк та механічна міцність

FDM-друк на верстаті Snapmaker A350 створює деталь пошарово з розплавленої нитки пластику.

Питання 4.1: Деталь у вигляді довгого важеля роборуки відчуває навантаження на злам. Як її правильно орієнтувати на столі принтера?

5

Компетентність 5: Алгоритм пошуку помилок (Troubleshooting)

Ти підключаєш Arduino Uno до комп'ютера, але світлодіод ON не загорівся, а комп'ютер видає звук вимкнення пристрою.

Питання 5.1: Яка дія має бути ПЕРШОЮ за правилами безпеки та діагностики?

6

Компетентність 6: Інженерна безпека в лабораторії

У нашій лабораторії працюють 3D-принтери з гарячими соплами (205–250°C), лазерні модулі та рухомі лінійні модулі Snapmaker A350.

Питання 6.1: Що суворо заборонено робити під час активного руху осей верстата Snapmaker?

🔗 Де це працює в реальному залізі

Сучасна інженерія — це синтез дисциплін. У провідних R&D-лабораторіях (Boston Dynamics, SpaceX, виробники БПЛА):

  • Міждисциплінарний розподіл: 3D-конструктор повинен розуміти розміри плати та тепловиділення компонентів, а програміст мікроконтролерів — знати фізику роботи приводів та допустимі навантаження на пластик.
  • Культура відмовостійкості: перш ніж запускати серію або дорогий дослідний зразок, перевіряють усі ланцюги живлення на КЗ, оскільки одна помилка в полярності спалює рідкісні чипи.
