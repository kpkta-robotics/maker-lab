УРОК 01 · Твій перший сигнал

Через 30 хвилин маленька плата подасть світлом сигнал SOS, і програму для неї напишеш ти.

⏱ ~45 хв основа + бонус 🧠 Нічого знати не треба 💻 Тільки браузер, плата не обов'язкова

Уяви світну куртку для велосипедиста, яка сама блимає в темряві. Або лампу, що вмикається, коли ти заходиш у кімнату. Або горщик, який сам просить води.

Усе це роблять невеликі плати з мозком, такі як Arduino. У них немає екрана, зате вони відчувають світ (світло, дотик, тепло, відстань) і керують світлом, звуком, моторами. Сьогодні ти зробиш перший крок: навчиш плату говорити світлом.

🛡 Не бійся помилитися
Усе, що ми робимо, відбувається у симуляторі, тобто у віртуальній майстерні в браузері. Зламати там нічого неможливо. Помилився? Просто натисни «Стоп» і спробуй ще раз.

🎯 Твоя місія на сьогодні

    Зробити те саме, але вже на справжній платі Arduino у віртуальній лабораторії Wokwi, а потім навчити її подавати SOS, міжнародний сигнал біди. Для цього треба знати лише кілька слів:
  


  
📖 Слова, які ти почуєш

  

    
Arduino (Ардуїно)
Маленька плата, яка виконує твою програму. Це як мозок для пристрою.

    
Програма (код)
Інструкція для плати: «зроби це, потім оце». Ми пишемо її спеціальною мовою, схожою на англійську.

    
Пін
Один контакт-«рознімання» на платі. Через нього плата подає на пристрій сигнал.

    
Світлодіод (LED)
Маленька лампочка. Світиться, коли на нього подати струм.

    
Резистор
Маленька деталь-«обмежувач». Не пускає у світлодіод занадто багато струму.

    
Симулятор (Wokwi)
Віртуальна майстерня в браузері. Усе працює як насправді, але нічого не зламати.

  


  
  
1
Перший успіх: жодного дроту

  
На самій платі Arduino вже є крихітний світлодіод із літерою L. Ми змусимо блимати саме його, тому збирати нічого не треба.


  
    
    
  1. Відкрий Wokwi: новий проєкт Arduino Uno (відкриється в новій вкладці). Wokwi англійською, це нормально.
    2. 
    
  2. У лівій частині екрана знайди вкладку sketch.ino. Там уже є чужий код.
    3. 
    
  3. Клікни у вікно коду, натисни Ctrl + A (виділити все) і Delete.
    4. 
    
  4. Скопіюй код нижче (кнопка «Копіювати») і встав у порожнє вікно: Ctrl + V.
    5. 
    
  5. Натисни велику зелену кнопку ▶ над схемою.
    6. 
  


  

    

void setup() {
  pinMode(LED_BUILTIN, OUTPUT);
}

void loop() {
  digitalWrite(LED_BUILTIN, HIGH);
  delay(1000);
  digitalWrite(LED_BUILTIN, LOW);
  delay(1000);
}

  


  
🎉 Перший успіх!

    Якщо на платі блимає маленький світлодіод, у тебе щойно вийшло запрограмувати свій перший пристрій. Серйозно: більшість людей ніколи цього не пробували.


  
Що вийшло в коді? Читаємо його як речення

  

    
РядокЛюдською мовою

    
void setup()«Підготовка». Виконується один раз, коли плату вмикають.

    
pinMode(LED_BUILTIN, OUTPUT)«Пін, до якого підключений світлодіод L, буде видавати сигнал».

    
void loop()«Повторювати завжди». Усе всередині крутиться по колу.

    
digitalWrite(..., HIGH)«Увімкни світлодіод».

    
delay(1000)«Чекай 1000 мілісекунд» (це 1 секунда).

    
digitalWrite(..., LOW)«Вимкни світлодіод».

  


  

    😕 Не виходить? Перевір це
    
    
      
  • Світлодіод не блимає. Чи натиснуто зелену кнопку ▶? Чи не залишилася кнопка «Стоп» червоною?
    • 
      
  • Червоний текст помилки внизу. Часто це забута крапка з комою ; в кінці рядка або зайва/відсутня дужка { }. Скопіюй код ще раз повністю.
    • 
      
  • Код не вставився. Спочатку клікни у вікно коду, потім Ctrl + A, Delete, Ctrl + V.
    • 
      
  • Нічого не змінюється. Онови сторінку Wokwi й почни спочатку. Втрачати немає чого.
    • 
    

  


  
  
2
Додаємо власний світлодіод

  
Світлодіод L на платі маленький. Додамо свій, великий червоний, який видно добре. Тепер уже треба трохи «зібрати», але нічого складного: три деталі й три дроти.


  

  
    
    
  1. У Wokwi натисни синю кнопку «+» (Add a new part) над схемою. Вибери LED і постав на екран. Потім так само додай Resistor.
    2. 
    
  2. Клікни на резистор і встанови значення 220 (Ом).
    3. 
    
  3. Щоб з'єднати: клікни на один контакт, потім на другий. З'явиться дріт. Зроби так:
      
      
        
    • пін 13 плати → один бік резистора;
      • 
        
    • інший бік резистора → A (анод, довга ніжка) світлодіода;
      • 
        
    • C (катод, коротка ніжка) світлодіода → GND плати.
      • 
      
    
    
    4. 
    
  4. У коді замість LED_BUILTIN напиши 13, або встав готовий код нижче.
    5. 
  


  

    

const int LED_PIN = 13;        // номер піна, до якого підключений світлодіод

void setup() {
  pinMode(LED_PIN, OUTPUT);    // цей пін видає сигнал
}

void loop() {
  digitalWrite(LED_PIN, HIGH); // увімкнути
  delay(1000);                 // чекати 1 секунду
  digitalWrite(LED_PIN, LOW);  // вимкнути
  delay(1000);                 // чекати 1 секунду
}

  


  

    
💬 Навіщо потрібен резистор?

    Уяви, що струм це вода в трубі, а світлодіод це крихкий скляний кухоль. Якщо направити в нього воду з повної сили, він трісне. Резистор, це вузьке місце в трубі: він пускає рівно стільки води, скільки кухоль витримає. Правило майстерні: світлодіод завжди ставимо через резистор 220 Ом.
  


  

    🧮 Для цікавих: як вирахувати цей резистор (можна пропустити)
    
Живлення дає 5 В. Червоний світлодіод «забирає» близько 2 В. Решта 3 В мають лишитися на резисторі. Безпечний струм для світлодіода близько 15 мА (0,015 А).

    
Закон Ома: R = U / I = 3 В / 0,015 А = 200 Ом. Найближчий стандартний резистор у наборі ТЕКО: 220 Ом, струм при цьому ≈ 13,6 мА.

Пограй із часом

  
Завдання: зроби так, щоб світлодіод світився 2 секунди і не світився півсекунди.

  
Підказка: змінюються лише числа в дужках delay( ). Півсекунди це 500 мілісекунд. Можеш потренуватися на віртуальному маяку вгорі сторінки.

5
Виклик: сигнал SOS

  
SOS в азбуці Морзе це три короткі, три довгі, три короткі спалахи (· · ·  — — —  · · ·). Натисни «Показати SOS» на віртуальному маяку вгорі, щоб побачити, як це виглядає. Обери свій рівень:


  

    

      
      
      
      
    

    

      Explorer: «Я досліджую». Почни з готового рішення нижче (відкрий блок «Рішення»). Запусти його у Wokwi, потім зміни швидкість: число UNIT (спробуй 100 і 400). Поясни своїми словами, що робить кожен рядок.
    

    

      Builder: «Я доповнюю». Напиши SOS сама(сам) через дві функції: dot() (короткий спалах) і dash() (довгий). Додай паузу 2 секунди між повтореннями сигналу.
    

    

      Maker: «Я проєктую». Додай другий світлодіод (інший колір) на пін 12: він має світитися лише в паузі між сигналами SOS. Підключи його так само, через резистор 220 Ом.
    

    

      Master: «Я оптимізую». Перепиши SOS без delay(): використай millis() і масив тривалостей. Мета: щоб плата могла «одночасно» робити щось інше.
    

  


  

    👀 Рішення SOS (відкривай після власної спроби!)
    

      

const int LED_PIN = 13;
const int UNIT = 200;          // одна «одиниця часу» в мс: крапка = 1, тире = 3

void dot()  {                  // короткий спалах
  digitalWrite(LED_PIN, HIGH); delay(UNIT);
  digitalWrite(LED_PIN, LOW);  delay(UNIT);
}

void dash() {                  // довгий спалах
  digitalWrite(LED_PIN, HIGH); delay(UNIT * 3);
  digitalWrite(LED_PIN, LOW);  delay(UNIT);
}

void setup() {
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  for (int i = 0; i < 3; i++) dot();   // S: · · ·
  delay(UNIT * 2);                      // пауза між літерами
  for (int i = 0; i < 3; i++) dash();  // O: — — —
  delay(UNIT * 2);
  for (int i = 0; i < 3; i++) dot();   // S: · · ·
  delay(UNIT * 7);                      // пауза перед повторенням
}

    

    
Що тут хитрого: одні й ті самі дії винесені у dot() і dash(), а цикл for повторює їх тричі, і не треба писати три однакові рядки. Це перший крок до охайного коду.

  


  
  
6
Перевір себе (спочатку подумай, потім відкривай)

  
1. Що робить delay(1000)?
    
Змушує плату чекати 1000 мілісекунд, тобто 1 секунду, перш ніж виконувати наступний рядок.

  
2. Чим відрізняється HIGH від LOW?
    
HIGH означає «увімкнено» (пін подає струм), LOW означає «вимкнено».

  
3. Чим setup() відрізняється від loop()?
    
setup() виконується один раз на початку, loop() повторюється безкінечно.

  
4. Навіщо світлодіоду резистор?
    
Щоб обмежити струм і не спалити світлодіод (як вузьке місце в трубі, що не пускає забагато води).

Бонус: на справжній платі ТЕКО за бажанням

  

    
🔌 Працюєш зі справжньою платою ТЕКО вперше?

    Плати ТЕКО мають USB-UART міст CH340, який потребує системного драйвера. Якщо плата не з'являється у списку портів або Arduino IDE видає помилку, скористайся нашою інструкцією: Посібник із налаштування Arduino IDE та драйвера CH340 →
  

  
Якщо у тебе є набір ТЕКО, можна повторити все «по-справжньому»:

  
    
    
  1. Підключи Arduino Uno до комп'ютера USB-кабелем.
    2. 
    
  2. Відкрий програму Arduino IDE. У меню Tools → Board вибери Arduino Uno, а в Port вибери порт плати.
    3. 
    
  3. Спочатку відключи USB, збери схему з дротів так само, як у Wokwi, потім підключи кабель.
    4. 
    
  4. Встав код і натисни кнопку → «Завантажити» (Upload).
    5. 
  

  
⚡ Безпека

    Ніколи не підключай світлодіод без резистора. Не міняй дроти, коли плата підключена до USB. Якщо щось гріється чи пахне, одразу відключи кабель і покажи викладачу.
