01

Вхідний сигнал: як мікроконтролер відчуває зовнішній світ

Перехід від сліпого виконання команд до реагування на дію людини.

В Уроці 01 плата лише віддавала накази у зовнішній світ: «увімкни світлодіод → зачекай → вимкни». Вона працювала як заведений годинник, не помічаючи, що відбувається навколо.

Справжні інженерні пристрої (від кнопки вмикання смартфона до датчиків паркування авто чи кінцевиків 3D-принтера) починаються з цифрових входів (INPUT). Сьогодні ми під'єднаємо до Arduino кнопку й навчимо плату фіксувати натискання. Але звичайна кнопка вимагає розуміння важливого фізичного явища!

💡 Де це застосовується у верстаті Snapmaker A350:

Кінцеві вимикачі (Endstops), які визначають нульову точку сопла 3D-принтера по осях X, Y, Z перед кожним друком — це точно такі ж тактові кнопки, підключені в режимі INPUT_PULLUP! Коли металева каретка доїжджає до краю осі, вона натискає кнопку й замикає вхід на землю (GND).

02

Лабораторія 1: Віртуальна кнопка та зворотна логіка

Затисни червону кнопку мишкою або пальцем на екрані та подивись на показники піна.

Інтерактивний стенд: Тактова кнопка + Пін 2 (INPUT_PULLUP)

Обирай режим: «Тактовий» (світить поки тримаєш) або «Тригер» (клік — увімкнув, клік — вимкнув).

Затисни кнопку
Вхідний пін 2: HIGH (5V / Підтягнуто)
Стан світлодіода (Пін 13): LOW (Не світиться)
Активний режим: Тактовий ліхтарик
LED 13 
// Натискання замикає пін 2 на GND:
if (digitalRead(2) == LOW) {
  digitalWrite(13, HIGH); // Світиться
} else {
  digitalWrite(13, LOW);  // Гасне
}

Зверни увагу на зворотну логіку (Active LOW): у режимі підтяжки ненатиснута кнопка дає HIGH, а при натисканні струм стікає в землю і значення стає LOW.

03

Пастка кнопки: проблема «плаваючого входу» (Floating Pin)

Чому не можна підключати кнопку просто «в повітря» без підтяжки.

Здавалося б, найпростіша схема — подати 5V через кнопку на пін. Натискання — іде 5V, відпускання — нічого не йде. Але в цифровій мікроелектроніці «нічого не йде» не означає 0 Вольт!

⚡ Плаваючий контакт — це радіоантена

Коли контакт кнопки розімкнено, пін Arduino висить у повітрі. Він починає вловлювати електромагнітні наведення від проводів у стінах, статичний заряд від пальців і випадково перемикатися між 0 і 1 сотні разів на секунду! Світлодіод блиматиме хаотично, навіть якщо до кнопки ніхто не торкається.

Щоб на вході завжди був чіткий рівень напруги, інженери ставлять підтягувальний резистор (Pull-up) на 10–30 кОм до лінії +5V. Розробники мікроконтролера ATmega328P вмонтували такі резистори всередину самого чипа на кожному піні! Достатньо лише написати в налаштуваннях одне слово: pinMode(2, INPUT_PULLUP);.

04

Збираємо схему у Wokwi: всього 2 дроти без зайвих деталей

Завдяки INPUT_PULLUP схема кнопки стає рекордно простою.

  1. Відкрий симулятор: Wokwi Arduino Uno ↗.
  2. Натисни кнопку «+» угорі та додай компонент Pushbutton.
  3. З'єднай лише два контакти:
    • Один контакт кнопки (пін 1.l) з'єднай із цифровим піном 2 на платі (синій дріт);
    • Діагональний контакт кнопки (пін 2.l) з'єднай із піном GND на платі (чорний дріт).
  4. Світлодіод використовуємо вбудований на піні 13 (позначений буквою L) або свій з Уроку 01.
05

Перший код: Кишеньковий ліхтарик

Читання стану піна за допомогою digitalRead() та логічна перевірка if-else.

lesson_02_button.ino 
const int BUTTON_PIN = 2; // Кнопка на піні 2
const int LED_PIN = 13;    // Світлодіод L на піні 13

void setup() {
  pinMode(LED_PIN, OUTPUT);
  // Вмикаємо вхід з внутрішнім резистором підтяжки до +5V:
  pinMode(BUTTON_PIN, INPUT_PULLUP);
}

void loop() {
  // Зчитуємо стан піна (HIGH або LOW):
  int buttonState = digitalRead(BUTTON_PIN);

  // Оскільки активна дія замикає пін на GND:
  if (buttonState == LOW) {
    digitalWrite(LED_PIN, HIGH); // Світло увімкнено
  } else {
    digitalWrite(LED_PIN, LOW);  // Світло вимкнено
  }
}

Розбір ключових рядків:

КомандаІнженерний зміст
pinMode(BUTTON_PIN, INPUT_PULLUP);Налаштовує пін на прослуховування сигналу та підключає внутрішній резистор 30 кОм до +5V.
int buttonState = digitalRead(BUTTON_PIN);Вимірює напругу: повертає HIGH (~5V) або LOW (0V) та зберігає у змінну.
if (buttonState == LOW)Перевіряє умову: якщо кнопку замкнено на «землю» — виконується блок увімкнення світла.
06

Брязкіт контактів (Contact Bounce) та вимикач-тригер

Чому механічні контакти пружинять і як усунути хибні спрацьовування програмно.

Спробуймо зробити справжній вимикач люстри: один клік — світло ввімкнулося і горить далі, другий клік — світло згасло. Для цього потрібна змінна пам'яті попереднього стану кнопки.

Але тут проявляється фізика металу: коли дві пружні пластинки стикаються, вони мікроскопічно пружинять протягом 2–5 мілісекунд. Для людини це 1 клік, а мікроконтролер, який виконує 16 мільйонів операцій на секунду, встигає зафіксувати 10–30 окремих перемикань!

Осцилограф брязкоту: реальний сигнал проти фільтрованого

Подивись на форму електричного сигналу в момент зіткнення металевих контактів.

Програмне лікування (Debounce): пауза delay(50); після першого зафіксованого переходу дозволяє контактам повністю заспокоїтися перед наступним зчитуванням.

07

AI-ментор: створення надійного антидребезгу без delay()

Професійний підхід: використання millis() для роботи кнопки без затримки всієї програми.

🤖 Шаблон промпту для створення неблокуючого тригера кнопки: 
Я пишу прошивку Arduino для тактової кнопки на піні 2 (режим INPUT_PULLUP).
Завдання: створити перемикач-тригер світлодіода на піні 13 (один клік вмикає, наступний вимикає).
Вимоги до коду:
1. Обов'язковий програмний захист від брязкоту контактів (debounce).
2. Заборонено використовувати delay(), оскільки пристрій одночасно повинен виконувати плавне регулювання чи інші задачі.
3. Використай таймер millis() та відстеження зміни стану кнопки з HIGH на LOW (falling edge).
Поясни логіку збереження попереднього стану кнопки (lastButtonState).
