📖 Інженерний словничок уроку

  

    
INPUT (Вхід)

    
Режим піна, коли Arduino слухає зовнішній сигнал (як вухо людини), а не подає струм.


    
INPUT_PULLUP (Вхід із підтягуванням)

    
Спеціальний режим Arduino: мікроконтролер сам підключає всередині чипа крихітний резистор до +5V. Коли кнопку відпущено — на вході стабільні 5 вольт (HIGH). Коли кнопку натискають і замикають на GND — струм стікає в землю і на вході стає 0 вольт (LOW).


    
digitalRead(pin)

    
Команда прочитати цифровий стан: повертає або HIGH (є напруга), або LOW (напруги немає / 0V).


    
Зворотна логіка (Active LOW)

    
Логіка роботи, коли активна дія (натискання) відповідає сигналу LOW, а спокій — HIGH.


    
Брязкіт контактів (Contact Bounce)

    
Механічна особливість будь-якої кнопки: коли металеві пластинки стикаються, вони мікроскопічно пружинять кілька мілісекунд, викликаючи 10–50 хибних натискань за мить.

Головна пастка кнопки: проблема «плаваючого входу»

  
Здавалося б, підключити кнопку найпростіше: подати 5V через кнопку на пін Arduino. Натиснув — пішло 5V, відпустив — нічого не йде. Але в мікроконтролерах «нічого не йде» не означає 0 Вольт!


  

    
⚡ Що таке плаваючий стан (Floating Pin)?

    Коли контакт кнопки розімкнений, пін Arduino висить у повітрі, як крихітна радіоантена. Він починає ловити електромагнітні наведення з кімнати, статичний заряд від твоїх пальців і випадково перемикатися між 0 і 1 сотні разів на секунду! Світлодіод блиматиме хаотично, навіть якщо кнопку ніхто не чіпає.
  


  
Щоб цього уникнути, інженери минулого ставили додатковий підтягувальний резистор (Pull-up) на 10 кОм. Але розробники Arduino зробили подарунок: цей резистор уже вмонтований усередині процесора! Достатньо лише вказати в коді чарівне слово INPUT_PULLUP.

Перший код: Кишеньковий ліхтарик

  
Давай напишемо програму: світлодіод вмикається, коли ми натискаємо й утримуємо кнопку, і гасне, коли відпускаємо.


  

    

// Урок 02: Проста кнопка з INPUT_PULLUP
const int BUTTON_PIN = 2;   // Кнопка підключена до піна 2
const int LED_PIN = 13;     // Світлодіод підключений до піна 13

void setup() {
  // Налаштовуємо пін світлодіода на ВИХІД (подавати сигнал)
  pinMode(LED_PIN, OUTPUT);

  // Налаштовуємо пін кнопки на ВХІД із ВНУТРІШНЬОЮ ПІДТЯЖКОЮ
  pinMode(BUTTON_PIN, INPUT_PULLUP);
}

void loop() {
  // Зчитуємо стан піна 2 (отримуємо або LOW, або HIGH)
  int buttonState = digitalRead(BUTTON_PIN);

  // Оскільки у нас INPUT_PULLUP:
  // LOW  = кнопка натиснута (замкнена на GND)
  // HIGH = кнопка відпущена (підтягнута до 5V)
  if (buttonState == LOW) {
    digitalWrite(LED_PIN, HIGH); // Увімкнути світлодіод
  } else {
    digitalWrite(LED_PIN, LOW);  // Вимкнути світлодіод
  }
}

  


  
Встав код у вікно Wokwi та натисни зелену кнопку ▶ Запустити. Клікни мишкою на червону кнопку в симуляторі й тримай її: світлодіод яскраво світиться!

Лабораторія «Зламай його» (Break-It Challenge)

  
Справжній інженер розуміє код найкраще тоді, коли сам його зламає й побачить причину несправності. Зроби ці три експерименти:


  

    
    
    
  


  

    
Експеримент: Заміни INPUT_PULLUP на звичайний INPUT

    
Зміни в setup() рядок на: pinMode(BUTTON_PIN, INPUT); і запусти симуляцію.

    
Що відбувається: Світлодіод може взагалі не реагувати або зависати у свіченні, тому що вхід «повис у повітрі». Тепер ти на власні очі бачиш, навіщо потрібен резистор підтяжки!

  


  

    
Експеримент: Напиши if (buttonState = LOW)

    
Заміни подвійне дорівнює == на одне дорівнює =.

    
Що станеться: Одне дорівнює = — це дія «записати значення», а не «перевірити рівність». Arduino видасть попередження або умова спрацьовуватиме неправильно. Для перевірки умов у мові C++ ЗАВЖДИ використовують подвійне ==!

  


  

    
Експеримент: Видали блок else { digitalWrite(LED_PIN, LOW); }

    
Залиш тільки частину з if, запусти проєкт і натисни кнопку один раз.

    
Що відбувається: Світлодіод увімкнувся... і більше ніколи не вимикається! Чому? Бо мікроконтролер виконує лише те, що йому прямо наказали. Якщо ти не наказав вимкнути при відпусканні — він триматиме світло вічно.

Рівні майстерності: обери свій челендж


  

    

      
🟢 Рівень 1: Explorer

      
Інвертор сигналізації. Перероби код так, щоб світлодіод горів постійно («чергове світло»), а коли натискаєш кнопку — він ГАСНУВ (сигнал тривоги).

    

    

      
🟡 Рівень 2: Builder

      
Кнопка-вимикач (Toggle). Зроби так, щоб не треба було тримати кнопку пальцем. Один клік — увімкнув світло, другий клік — вимкнув (як торшер у кімнаті).

    

    

      
🟠 Рівень 3: Maker

      
Подолання брязкоту (Debounce). Додай після зчитування кнопки невелику затримку delay(50) і перевір, наскільки стабільніше став перемикатися стан.

    

    

      
🔴 Рівень 4: Master

      
Перемикач режимів маяка. Якщо кнопку не чіпають — світлодіод повільно блимає (1 раз на секунду). Якщо кнопку затиснули — він починає блимати в режимі тривоги SOS!

    

  


  

    💡 Підказка та готовий код для Рівня 2 (Кнопка-вимикач)
    
Щоб запам'ятати стан, потрібна логічна змінна (прапорець) типу bool, яка може бути або true (вкл), або false (викл):

    

      

const int BUTTON_PIN = 2;
const int LED_PIN = 13;
bool ledState = false; // Початковий стан: вимкнено

void setup() {
  pinMode(LED_PIN, OUTPUT);
  pinMode(BUTTON_PIN, INPUT_PULLUP);
}

void loop() {
  // Якщо зловили натискання
  if (digitalRead(BUTTON_PIN) == LOW) {
    ledState = !ledState; // Змінюємо стан на протилежний (! означає "НЕ")
    digitalWrite(LED_PIN, ledState ? HIGH : LOW);
    
    delay(250); // Пауза проти брязкоту контактів і повторного спрацювання
    while (digitalRead(BUTTON_PIN) == LOW) {
      // Чекаємо, доки людина прибере палець з кнопки
    }
  }
}

Перевір себе

  

    1. Чому при використанні INPUT_PULLUP натиснута кнопка дає LOW, а не HIGH?
    
Тому що кнопка підключається між піном і землею (GND). Коли контакт замикається, напруга стікає в 0V (землю), що для мікроконтролера є сигналом LOW.

  

  

    2. Що станеться, якщо підключити кнопку до піна з режимом INPUT без резистора?
    
Пін опиниться у «плаваючому» стані (Floating). Він вловлюватиме електромагнітний шум навколишнього середовища і випадково видаватиме то 0, то 1.

  

  

    3. Що таке «брязкіт контактів» (Bounce)?
    
Це механічне пружиніння контактів кнопки під час натискання. Замість одного перемикання плата може вловити декілька мікроімпульсів протягом 5–20 мілісекунд.

  

  

    4. Чим digitalRead() відрізняється від digitalWrite()?
    
digitalRead() — це вхід (читаємо значення з піна), а digitalWrite() — це вихід (віддаємо наказ встановити напругу).
