УРОК 03 · Розумний світлофор: кілька світлодіодів і масиви

Керуємо кількома пристроями одночасно. Дізнаємося, як масиви та цикли рятують інженера від нескінченного копіпасту, і створюємо автоматичне міське перехрестя.

⏱ ~60–80 хв 🧠 Потрібні Уроки 01 і 02 💻 Wokwi або набір ТЕКО

Один світлодіод — це маяк або ліхтарик. Але в реальних системах (роботи, автомобілі, промислові верстати) контролер одночасно керує десятками індикаторів, двигунів і датчиків.

Сьогодні ти створиш справжній міський світлофор з усіма його правилами: червоний, червоний+жовтий, зелений, блимання зеленого та жовтий. А головне — навчишся писати професійний код без повторення однакових рядків за допомогою масивів і циклів for.

🏆 Золоте правило програміста: DRY
DRY = Don't Repeat Yourself (Не повторюй себе). Якщо ти копіюєш один і той самий рядок у коді 5 разів — зупинись! Справжній інженер змушує комп'ютер робити рутину за допомогою циклів.

📖 Інженерний словничок уроку

  

    
Масив (Array)

    
Впорядкований ланцюжок однакових змінних. Як коробка для яєць або шафа з пронумерованими шухлядами: в одну змінну з ім'ям ledPins ми можемо покласти номери {12, 11, 10}.


    
Індекс елемента (Index)

    
Порядковий номер елемента в масиві. Увага: у програмуванні рахунок ЗАВЖДИ починається з нуля! Перший елемент — це [0], другий — [1], третій — [2].


    
Цикл for

    
Спеціальна конструкція для повторення дій визначену кількість разів. Наприклад, щоб налаштувати всі три піни, ми пишемо цикл від 0 до 2.


    
Шина живлення (Breadboard Rails)

    
Довгі сині та червоні лінії з боків макетної плати. До них підключають GND або +5V, щоб роздати живлення одразу на багато компонентів за допомогою одного дроту.

Магія масивів та циклу for

  
Як налаштувати піни 12, 11, 10 на вихід? Початківець напише:


  


// ❌ Початковий підхід (багато однакових рядків)
pinMode(12, OUTPUT);
pinMode(11, OUTPUT);
pinMode(10, OUTPUT);

  


  
А якщо у нас 16 світлодіодів у матриці? Писати 16 рядків? Ні! Інженер використовує масив і цикл for:


  


//  Інженерний підхід: масив і цикл
const int ledPins[] = {12, 11, 10}; // список пінів світлофора

for (int i = 0; i < 3; i++) {
  pinMode(ledPins[i], OUTPUT);      // налаштує піни 12, 11, 10 автоматично!
}

  


  
Як читати цикл for (int i = 0; i < 3; i++):

  

    
Частина циклуЩо це означає

    
int i = 0;Старт: створюємо лічильник i зі значенням 0.

    
i < 3;Умова: крутимо цикл, доки i менше 3 (тобто для значень 0, 1, 2).

    
i++Крок: після кожного кола збільшуємо i на 1.

    
ledPins[i]Дістаємо значення: коли i=0 — беремо 12; коли i=1 — беремо 11; коли i=2 — беремо 10.

Повний код справжнього світлофора

  
Скопіюй цей скетч у Wokwi. Тут реалізовано повний український стандарт: фаза попередження перед рухом та блимаючий зелений сигнал перед зупинкою!


  

    

// Урок 03: Розумний міський світлофор
const int PIN_RED = 12;
const int PIN_YELLOW = 11;
const int PIN_GREEN = 10;

// Масив усіх пінів світлофора
const int ledPins[] = {PIN_RED, PIN_YELLOW, PIN_GREEN};
const int NUM_LEDS = 3;

// Зручна функція: вимкнути всі вогні одразу
void allOff() {
  for (int i = 0; i < NUM_LEDS; i++) {
    digitalWrite(ledPins[i], LOW);
  }
}

void setup() {
  // Налаштовуємо всі піни світлофора одним циклом
  for (int i = 0; i < NUM_LEDS; i++) {
    pinMode(ledPins[i], OUTPUT);
  }
}

void loop() {
  // 1. ЧЕРВОНИЙ: проїзд заборонено (3 секунди)
  allOff();
  digitalWrite(PIN_RED, HIGH);
  delay(3000);

  // 2. ЧЕРВОНИЙ + ЖОВТИЙ: приготуватися до руху (1 секунда)
  digitalWrite(PIN_YELLOW, HIGH);
  delay(1000);

  // 3. ЗЕЛЕНИЙ: рух дозволено (3 секунди)
  allOff();
  digitalWrite(PIN_GREEN, HIGH);
  delay(3000);

  // 4. ЗЕЛЕНИЙ БЛИМАЄ: попередження про завершення (3 спалахи)
  for (int i = 0; i < 3; i++) {
    digitalWrite(PIN_GREEN, LOW);
    delay(350);
    digitalWrite(PIN_GREEN, HIGH);
    delay(350);
  }

  // 5. ЖОВТИЙ: увага, зупинитися (1.5 секунди)
  allOff();
  digitalWrite(PIN_YELLOW, HIGH);
  delay(1500);

  // Цикл завершується і починається знову з червоного!
}

  


  
Запусти симуляцію у Wokwi та спостерігай за плавним переходом вогнів. Зверни увагу, як охайно функція allOff() очищає стан світлофора перед кожною новою фазою!

Як зламати світлофор, щоб краще зрозуміти помилки? Спробуй ці три інженерні пастки:


  

    
    
    
  


  

    
Експеримент: Спробуй звернутися до ledPins[3]

    
У нашому масиві 3 елементи: з індексами 0, 1, 2. Що станеться, якщо написати digitalWrite(ledPins[3], HIGH);?

    
Чому це небезпечно: У C++ елемента з індексом 3 не існує! Arduino прочитає випадкове сміття з сусідньої комірки пам'яті й може подати сигнал на зовсім несподіваний пін або зависнути. Це одна з найчастіших помилок початківців!

  


  

    
Експеримент: Напиши в циклі i <= NUM_LEDS замість i < NUM_LEDS

    
Знак «менше або дорівнює» змусить цикл виконатися 4 рази (для i=0, 1, 2 і 3).

    
Результат: Цикл спробує налаштувати неіснуючий 4-й пін. Пам'ятай: для масиву довжиною N умова завжди сувора: i < N.

  


  

    
Експеримент: Закоментуй виклик allOff() перед увімкненням зеленого

    
Постав дві похилі риски // allOff(); перед зеленим сигналом.

    
Результат: У тебе одночасно горітимуть і червоний, і жовтий, і зелений вогні — справжня аварійна ситуація на дорозі! Завжди переконуйся, що попередній стан скинуто.

Перевір себе

  

    1. З якого номера починається нумерація елементів у масиві C++?
    
З нуля: перший елемент має індекс 0, другий — 1, третій — 2.

  

  

    2. Навіщо потрібен цикл for при роботі зі світлофором?
    
Щоб не дублювати однаковий код налаштування або вимкнення світлодіодів, а автоматично виконати команду для кожного піна з масиву.

  

  

    3. Що означає скорочення DRY у розробці?
    
Don't Repeat Yourself («Не повторюй себе») — фундаментальний принцип проектування програм, згідно з яким код не повинен містити дублювання однакових блоків.

  

  

    4. Чому всі світлодіоди можна підключити до одного піна GND?
    
GND — це загальна шина мінуса («земля»). Струм повертається через неї до джерела живлення, тому всі компоненти можуть мати спільну точку з'єднання з землею.
