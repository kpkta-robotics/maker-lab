Золотий закон програміста: принцип DRY

Don't Repeat Yourself (Не повторюй себе) — як писати код без хаосу.

Один світлодіод — це простий ліхтарик або маяк. Але в реальних мейкерських системах (роботизовані візки, маніпулятори, матричні дисплеї) мікроконтролер одночасно керує десятками індикаторів та приводів.

Якщо для налаштування трьох пінів копіювати рядок pinMode() тричі — це ще можна терпіти. Але якщо компонентів стає 8, 16 чи 64? Справжній інженер змушує комп'ютер виконувати рутину за допомогою масивів (Arrays) та циклів for.

💡 Де це працює у 3D-принтері:

Крокові двигуни осей Snapmaker A350 (X, Y, Z, Extruder) керуються послідовністю імпульсів на 4 піни кожен. Замість сотень окремих рядків у прошивці верстата працює один компактний масив пінів, по якому циклічно пробігає алгоритм крокування!

Лабораторія 1: Віртуальне перехрестя та фази світлофора

Запусти автоматичний цикл або перемикай фази вручну, спостерігаючи за кодом кожної фази.

Інтерактивний світлофор: Піни 12 (R), 11 (Y), 10 (G)

Спостерігай за послідовністю: Червоний → Червоний+Жовтий → Зелений → Блимання → Жовтий.

ФАЗА 1: Червоний сигнал (Стоп)
// Фаза 1: Червоний пін 12 = HIGH, решта = LOW
digitalWrite(ledPins[0], HIGH);
digitalWrite(ledPins[1], LOW);
digitalWrite(ledPins[2], LOW);
delay(3000);
03

Спільна шина «Земля» (GND Rail) на макетній платі

Як роздати мінус живлення одразу на багато компонентів за допомогою одного дроту.

На платі Arduino Uno є лише 3 контакти з позначкою GND. Якщо підключати кожен світлодіод окремим дротом у плату — контакти швидко закінчаться.

Для цього використовують довгі лінії з боків макетної плати (позначені синьою смугою та знаком «-»). Один чорний дріт від піна GND на Arduino підключається до цієї шини, і тепер усі 50 отворів цієї смужки стають контактами «землі»!

04

Що таке масив у C++: нумерація з нуля

Зберігання списку пінів в одній спільній змінній.

Масив — це впорядкований ланцюжок однакових змінних. Можна уявити його як коробку для деталей із пронумерованими відділеннями:

📦 Оголошення масиву номерів пінів:

const int ledPins[3] = {12, 11, 10};

Увага: у програмуванні індекси ЗАВЖДИ рахуються з нуля:

  • ledPins[0] — це число 12 (Червоний світлодіод)
  • ledPins[1] — це число 11 (Жовтий світлодіод)
  • ledPins[2] — це число 10 (Зелений світлодіод)
05

Цикл for: налаштування всіх пінів за 2 рядки

Як перетворити одноманітний код на елегантну інженерну конструкцію.

setup_with_for.ino 
const int ledPins[3] = {12, 11, 10};

void setup() {
  // Цикл for повторюється для i = 0, 1, 2:
  for (int i = 0; i < 3; i++) {
    pinMode(ledPins[i], OUTPUT);
  }
}

Цикл for (int i = 0; i < 3; i++) читається так: «створи лічильник i зі значенням 0; повторюй поки i менше 3; після кожного проходу збільшуй i на одиницю».

06

Повний код міського світлофора з блиманням зеленого

Повноцінний алгоритм згідно з правилами дорожнього руху.

traffic_light.ino 
const int ledPins[3] = {12, 11, 10}; // 0: Red, 1: Yellow, 2: Green

void setup() {
  for (int i = 0; i < 3; i++) {
    pinMode(ledPins[i], OUTPUT);
  }
}

void loop() {
  // 1. Червоний сигнал (Стоп) - 3 секунди
  digitalWrite(ledPins[0], HIGH);
  digitalWrite(ledPins[1], LOW);
  digitalWrite(ledPins[2], LOW);
  delay(3000);

  // 2. Червоний + Жовтий (Увага) - 1 секунда
  digitalWrite(ledPins[1], HIGH);
  delay(1000);

  // 3. Зелений сигнал (Рух) - 3 секунди
  digitalWrite(ledPins[0], LOW);
  digitalWrite(ledPins[1], LOW);
  digitalWrite(ledPins[2], HIGH);
  delay(3000);

  // 4. Зелений блимає 3 рази
  for (int b = 0; b < 3; b++) {
    digitalWrite(ledPins[2], LOW);
    delay(400);
    digitalWrite(ledPins[2], HIGH);
    delay(400);
  }

  // 5. Жовтий сигнал (Приготуватися) - 1.5 секунди
  digitalWrite(ledPins[2], LOW);
  digitalWrite(ledPins[1], HIGH);
  delay(1500);
  digitalWrite(ledPins[1], LOW);
}

AI-ментор: рефакторинг коду через структури

Як професійні розробники прошивок описують стани світлофора таблицею даних.

Я написав прошивку світлофора для Arduino з трьома світлодіодами через delay() та окремі виклики digitalWrite.

Покажи, як організувати фази світлофора у вигляді масиву структур (struct Phase { bool r, y, g; unsigned long duration; }), щоб головний цикл loop() став коротким скінченним автоматом (Finite State Machine).
