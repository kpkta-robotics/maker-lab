# Адаптивна цифрова майстерня: Arduino · CAD · 3D-друк · AI · Maker

Статичний сайт з послідовними уроками для студентів КПКТА імені Бадрі Лолашвілі.
Без фреймворків і без збірки: тільки HTML, CSS і JavaScript. Працює на GitHub Pages.

## Структура

```
arduino-course/
├── index.html              карта курсу + прогрес
├── assets/
│   ├── course.js           ЄДИНЕ місце, де описано модулі й уроки
│   ├── app.js              прогрес, розблокування, навігація, вкладки
│   └── style.css           спільні стилі
├── modules/
│   └── 01-arduino-basics/lesson-01.html
├── _template/lesson.html   шаблон нового уроку
└── .nojekyll
```

## Як додати новий урок

1. Скопіюйте `_template/lesson.html` у папку модуля, наприклад
   `modules/01-arduino-basics/lesson-02.html`.
2. У `<body>` змініть `data-lesson` на id уроку (наприклад `m1-l02`).
   Шлях `../../assets/...` лишається, якщо файл лежить у `modules/<модуль>/`.
3. Заповніть сторінку.
4. У `assets/course.js` знайдіть цей урок, змініть `status: "soon"` на `"ready"`
   і додайте `path: "modules/01-arduino-basics/lesson-02.html"`.
5. Зробіть commit і push. Карта курсу, кнопки «Назад/Далі» і розблокування оновляться самі.

Новий модуль: додайте об'єкт у масив `modules` у `course.js`.

## Як працює послідовність

- Прогрес зберігається в `localStorage` браузера студента (ключ `arduino-course-v1`).
- Наступний урок відкривається, коли попередній готовий урок позначено пройденим.
- Кнопка «Урок пройдено» стає активною, коли відзначено всі пункти чек-листа.
- **Режим викладача:** відкрийте сайт з `?teacher=1` (наприклад `index.html?teacher=1`),
  і всі уроки стануть доступні. Вимкнути: `?teacher=0`.

> Прогрес прив'язаний до браузера й пристрою, і це не захист від обходу.
> Для обліку успішності збирайте докази (скріншот, посилання на Wokwi) через
> Google Form або Classroom.

## Публікація на GitHub Pages

1. Створіть репозиторій на GitHub (наприклад `arduino-course`).
2. Завантажте **вміст папки `arduino-course`** у корінь репозиторію.
   З командного рядка в цій папці:
   ```
   git init
   git add .
   git commit -m "Початок курсу"
   git branch -M main
   git remote add origin https://github.com/<ваш-логін>/arduino-course.git
   git push -u origin main
   ```
3. На GitHub: **Settings → Pages → Build and deployment**:
   Source = *Deploy from a branch*, Branch = `main`, папка `/ (root)` → Save.
4. Через 1–2 хвилини сайт буде доступний за адресою
   `https://<ваш-логін>.github.io/arduino-course/`.

## Перевірка локально

Відкрийте `index.html` у браузері подвійним кліком. Усе працює без сервера.

## Правила для контенту

- Українською мовою, мобільна верстка.
- Кожен урок: місія → інвентар ТЕКО → коротка теорія → практика у Wokwi →
  Break-It → Challenge у 4 рівнях → самоперевірка → портфоліо.
- Не копіювати цілком чужі матеріали (PDF ТЕКО, уроки Tinkercad): робіть власні
  уроки й давайте посилання на оригінали.
- Відповіді для викладача, які не мають бути публічними, тримайте в окремому приватному репозиторії.
